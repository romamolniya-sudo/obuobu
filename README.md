# Полчаса в день

Курс общего развития: 91 день по 30 минут. Семь направлений по кругу: мышление и решения, деньги и инвестиции, психология и эмоции, люди и коммуникация, цели и продуктивность, тело и энергия, как устроен мир.

Каждый день: повторение карточек (3 мин), чтение (12 мин), практика (10 мин), тест (3 мин), заметка (2 мин).

## Как опубликовать на GitHub Pages

1. Создай новый репозиторий на github.com (например, `polchasa`).
2. «Add file» → «Upload files» → перетащи все файлы из этой папки → «Commit changes».
3. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<твой-логин>.github.io/polchasa/`.

## Как поставить на телефон

- **iPhone:** открой адрес в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** открой адрес в Chrome → меню ⋮ → «Добавить на главный экран».

Прогресс, ответы и заметки хранятся в браузере телефона. На iPhone иконка с экрана «Домой» хранит их отдельно от Safari, поэтому занимайся из иконки. Перед сменой телефона: «Заметки» → «Скопировать резервную копию», на новом устройстве — «Восстановить».

После первого открытия курс работает и без интернета.

## Как обновить

Загрузи новый `index.html` (и `sw.js`) в репозиторий поверх старых. Прогресс не потеряется.
